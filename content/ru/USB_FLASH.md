# Прошивка через USB

Режим USB использует последовательный порт для датчиков IDM, подключённых по USB.

![Интерфейс USB](../images/usb-workflow.svg)

## Выбор последовательного порта

- **Serial Port**: обычный порт устройства, например `/dev/serial/by-id/usb-idm_idm_...`
- **Bootloader Serial**: порт после перехода устройства в загрузчик; для уже запущенного загрузчика укажите его напрямую

В списке устройств показываются устройства с `IDM` в имени.

## Выбор прошивки

В режиме USB отображаются все доступные файлы прошивки без фильтрации по частоте.

## Вход и выход из загрузчика

- **Enter BL**: запрашивает перезапуск устройства в загрузчик
- **Exit BL**: использует последовательность prime, CONNECT, COMPLETE без переключения DTR

## Автообнаружение загрузчика

`Detect BL` проверяет текущий порт, `/dev/serial/by-id/*`, `/dev/ttyUSB*` и `/dev/ttyACM*`. Устройства, чьи имена содержат `katapult` или `canboot`, определяются как загрузчики.

## Процедура прошивки

1. Выберите режим USB
2. Выберите Serial Port или укажите Bootloader Serial
3. Выберите тип, версию и файл прошивки
4. При необходимости нажмите `Enter BL`
5. Нажмите `Detect BL` для проверки порта загрузчика
6. Нажмите `Start Flashing`
7. Дождитесь завершения по выводу консоли

# Прошивка в режиме DFU

В режиме DFU используется `dfu-util` для устройств в USB DFU.

## Требования

- Установите dfu-util: `sudo apt install -y dfu-util`
- Сначала выполняется запуск без sudo; при ошибке используется `sudo -n`

## Переход в режим DFU

Замкните BOOT0 и включите питание устройства.

## Адрес прошивки

| Адрес | Описание |
|-------|----------|
| 0x08002000 | Основная прошивка |
| 0x08000000 | Загрузчик |

## Обнаружение DFU-устройства

`Detect DFU` запускает `dfu-util -l` и ищет устройства в режиме DFU.

![Интерфейс DFU](../images/dfu-workflow.svg)

## Процедура прошивки

1. Выберите режим DFU
2. Выберите правильный адрес прошивки
3. Выберите файл прошивки
4. Нажмите `Detect DFU` для проверки устройства
5. Нажмите `Start Flashing`
6. Дождитесь перезапуска устройства и выхода из DFU

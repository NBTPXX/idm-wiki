# Прошивка через CAN

Режим CAN использует SocketCAN для связи с датчиками IDM, подключёнными к шине CAN.

## Выбор частоты CAN

Выбирайте частоту по сборке прошивки.

| Вариант | Частота | Описание |
|---------|---------|----------|
| 1000000 | 1M | Высокая скорость |
| 500000 | 500k | Средняя скорость |
| 250000 | 250k | Низкая скорость |
| Other | - | Прошивка без тега частоты |

## Типы прошивки

- **IDM Main Firmware (main)**: стандартная рабочая прошивка датчика
- **Bootloader Override Firmware (deployer)**: замена существующего загрузчика при первом развёртывании

## Вход и выход из загрузчика

- **Enter BL**: введите UUID CAN и отправьте `KLIPPER_REBOOT_CMD` на ID управления `0x3f0`
- **Exit BL**: выполняется последовательность clear node, set node ID, CONNECT, COMPLETE

![Интерфейс CAN](../images/can-workflow.svg)

## Поиск UUID CAN

Для прошивки нужен 6-байтный UUID устройства. Нажмите `Query`, чтобы найти Katapult-узлы на шине CAN.

- Устройство находится в режиме загрузчика Katapult
- Интерфейс CAN, например `can0`, настроен и включён

## Процедура прошивки

1. Выберите режим CAN
2. Выберите частоту и тип прошивки
3. Выберите версию и файл
4. Для работающего устройства введите UUID и нажмите `Enter BL`
5. Нажмите `Query` для получения UUID CAN
6. Нажмите `Start Flashing`
7. Дождитесь завершения по выводу консоли

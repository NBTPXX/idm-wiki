# Калибровка

## Инициализация положения Z

Перед калибровкой задайте исходное положение Z.

1. Выполните `G28 X Y`; ось Z не хоумится
2. Переместите сопло в центр стола
3. Выполните `SET_KINEMATIC_POSITION z=80`
4. Вручную опустите сопло до касания стола, используя лист бумаги
5. Выполните `SET_KINEMATIC_POSITION z=0`

## Ручная калибровка (режим Scan)

```gcode
IDM_CALIBRATE
```

## Режим Touch

Режим Touch калибрует датчик по контакту сопла со столом и подходит для любых поверхностей.

```gcode
IDM_TOUCH METHOD=MANUAL
G28
IDM_THRESHOLD_SCAN MIN=500
SAVE_TOUCH_OFFSET
PROBE_CALIBRATE METHOD=AUTO
```

Добавьте в макрос начала печати:

```gcode
IDM_TOUCH CALIBRATE=1
PROBE_CALIBRATE METHOD=AUTO
```

## Режим Second Probe

Для хоуминга Z и автоматической калибровки смещения Z используются TAP или механический концевой выключатель.

```ini
[scanner]
calibration_method: second_probe
z_offset: 0
probe_speed: 10
probe_pin:
```

| Параметр | Описание |
|----------|----------|
| `calibration_method` | Значение `second_probe` включает этот метод |
| `z_offset` | Фиксированное смещение высоты срабатывания от сопла |
| `probe_speed` | Скорость оси Z при калибровке; рекомендуется до 15 мм/с |
| `probe_pin` | Пин срабатывания TAP или механического концевика |

Сохраните конфигурацию, перезапустите Klipper и проверьте срабатывание датчика.

## Управление моделями

| Команда | Описание |
|---------|----------|
| `IDM_MODEL_SAVE NAME=<name>` | Сохранить текущую калибровку |
| `IDM_MODEL_SELECT NAME=<name>` | Загрузить сохранённую калибровку |
| `IDM_MODEL_LIST` | Показать список калибровок |
| `IDM_MODEL_REMOVE NAME=<name>` | Удалить калибровку |

# DFU モード書き込み

DFU モードでは `dfu-util` を使用します。USB DFU モードのデバイスに適用されます。

## 必要条件

- dfu-util をインストール: `sudo apt install -y dfu-util`
- 最初に sudo なしで実行し、失敗時は `sudo -n` を使用します

## DFU モードへの移行

BOOT0 をショートさせた状態でデバイスの電源を入れます。

## 書き込みアドレス

| アドレス | 説明 |
|---------|------|
| 0x08002000 | メインファームウェア |
| 0x08000000 | ブートローダー |

## DFU デバイスの検出

`Detect DFU` を押すと `dfu-util -l` を実行して DFU デバイスを検索します。

![DFU モード書き込み画面](../images/dfu-workflow.svg)

## 書き込み手順

1. DFU モードを選択します
2. 正しい書き込みアドレスを選択します
3. ファームウェアファイルを選択します
4. `Detect DFU` でデバイスを確認します
5. `Start Flashing` を押します
6. デバイスの再起動と DFU モード終了を待ちます
